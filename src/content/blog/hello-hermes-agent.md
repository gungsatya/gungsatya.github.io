## 🧠 Apa Itu Hermes Agent?

**[Hermes Agent](https://hermes-agent.nousresearch.com)** adalah framework AI agent open-source buatan [Nous Research](https://nousresearch.com) yang berjalan di terminal, desktop, dan berbagai platform messaging seperti Telegram, Discord, WhatsApp, dan lainnya.

### ✨ Fitur Unggulan

| Fitur | Deskripsi |
|-------|-----------|
| **Provider-Agnostic** | Bisa pakai 20+ provider LLM (OpenRouter, Anthropic, OpenAI, Google, DeepSeek, Ollama, dll) |
| **Multi-Platform** | Jalan di CLI, TUI, Desktop, Telegram, Discord, WhatsApp, dan 20+ platform lainnya |
| **Skills** | Bisa belajar dari pengalaman — menyimpan workflow reusable sebagai skill |
| **Memory** | Ingat preferensi user dan konteks lintas sesi |
| **Cron Jobs** | Jadwalkan task otomatis berulang |
| **Delegation** | Bisa spawning sub-agent untuk mengerjakan tugas paralel |
| **Tool Calling** | Akses file, terminal, web, browser, dan lainnya |

### 🛠️ Yang Bisa Dilakukan

- 💻 **Coding** — baca, tulis, edit, refactor code
- 🔍 **Research** — cari dan ekstrak informasi dari web
- 📁 **File Management** — kelola file dan direktori
- ⚙️ **System Admin** — jalankan perintah terminal, manage service
- 📅 **Scheduling** — cron job untuk pengingat dan tugas rutin
- 🤝 **Multi-Agent** — delegasi tugas ke sub-agent paralel
- 🏠 **Smart Home** — kontrol perangkat IoT dan Philips Hue

### 🔧 Cara Kerjanya

```
User Chat → Hermes Agent → LLM (Claude/GPT/DeepSeek...)
                ↓
         Tool Calling
          ├── Terminal
          ├── File System
          ├── Web Search
          ├── GitHub
          └── ... dan lainnya
```
